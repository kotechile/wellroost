# WellRoost — brand vocabulary

Preferred terms for this front. Enforcement lives in one place: `npm run copy:check` runs
`scripts/vibe/vibe-lint.mjs` against `scripts/vibe/lexicon.json` (vendored from the vibe-marketing
spec) on every build, and a hard violation fails it. The banned list — including the housing jargon
that used to live only here — is in that file; it is not restated here, because a second copy of a
banned list is how the two drift apart.

## Preferred terminology

- **Interactive Asset / Decision Engine** — for "lead magnet", "ebook", "renovation checklist",
  "downloadable PDF guide".
- **Net Yield / ROI Engine / Equity Recovery Ledger** — positioning copy only. The search-facing
  word stays "calculator": `/calculators/…`, H1s, nav labels and slugs are never renamed.
- **Agentic Plumbing / Telemetry Pipeline** — for "backend automation", "zapier zap",
  "workflow scripts".
- **Precision Mechanics / Empirical Framework** — for "advanced features", "cool tools",
  "renovation tips".
- **Comp ARV / Capital Expenditure (CapEx) Underwriting** — for "home valuation guess",
  "renovation cost estimate".
- **Total Cost of Ownership (TCO) / Payback Horizon** — for "energy savings", "utility discounts".
- **Over-Improvement Trap / Diminishing Returns Threshold** — for "costly remodeling mistakes".
- **Relocation Friction Delta / Carry Cost** — for "moving expenses", "mortgage hassle".

## Structure

Lead with the number or the conclusion, then the rule behind it. No introductory paragraph.
